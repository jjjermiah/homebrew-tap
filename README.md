# Jjjermiah Tap

## How do I install these formulae?

`brew install jjjermiah/tap/<formula>`

Or `brew tap jjjermiah/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jjjermiah/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
